# ToonSpectrum CC0 asset delivery

Actual original files are in assets/. Open index.html for search and downloads.

GLB files have embedded textures and can be imported with Studio 3D model import. Surface images can be used as material base-color textures; companion PBR maps are not separate assets. Effect masks are small 512px-or-better native masks, not full-panel art.

All source and license records travel with files. No fonts, paid assets, user uploads or user works are included. Technical checks, exclusions and duplicates are recorded. Artistic review and Studio runtime round-trip remain separate gates.
