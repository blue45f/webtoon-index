원본과 재제작물을 구분

보이지 않는 구조는 새로 설계했습니다. 숨긴 천장은 GLB 안에 별도 조립체로 포함됩니다. 원래 모델의 리깅·재질·치수 복원이나 경쟁 상품보다 높은 품질을 보증하지 않습니다.
